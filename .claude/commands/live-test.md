Прожени живий тест агента на реальному DeepSeek API.

УВАГА: це НЕ безкоштовно — кожен запуск робить ~10-20 викликів API. Не запускай у циклі
і не повторюй прогін «для певності» без причини.

Кроки:
1. Спершу `python uktzed_live_test.py --plumbing` (без API). Якщо не «plumbing OK» — стоп,
   звітуй про поломку харнесу, API не чіпай.
2. `python uktzed_live_test.py --dense`. Ключ агент бере з .env сам — не читай і не виводь .env.
3. Розбери вивід по кейсах:
   - жаргонні кейси (маяк-пінгер, болгарка): PASS вимагає і правильного коду, І >=2 пошуків —
     тобто модель переформулювала запит. Якщо код вірний, але пошук один — це FAIL правила 2a,
     подивись на список пошуків і процитуй його у звіті.
   - контрольні кейси: мають проходити з одного пошуку.
4. FAIL — НЕ привід правити код чи промт самостійно. Звітуй: кейс, очікуване/отримане,
   список пошукових запитів, хвіст відповіді моделі. Рішення про правки ухвалюється окремо.
5. Живий тест недетермінований: один FAIL може бути флуктуацією моделі. Можна повторити
   РІВНО ОДИН раз лише кейс, що впав, думкою: якщо повторно PASS — познач як flaky.

Формат звіту: рядок на кейс (PASS/FAIL/flaky, код, к-сть пошуків), вердикт одним рядком.
Нічого не комітити в git.
